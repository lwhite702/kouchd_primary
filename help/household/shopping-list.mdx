Every stay has a **Shopping list**. Find it in the web sidebar, or under **More** on iPhone.

## Add an item

Enter the item, and if you like, a quantity and a note such as "Unscented, please." Then choose a list:

- **Shared with the house:** Everyone in the stay can see it.
- **Personal:** Only you can see it. That includes your host and other guests.

Check an item off when you've got it, or edit or remove it anytime.

<Note>
  The list is just a list. Checking something off doesn't create a contribution or change a balance. If you bought something you agreed to share, [add a contribution](/help/guests/logging-contributions) too.
</Note>
