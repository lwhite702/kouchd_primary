---
title: "House guide"
description: "Keep Wi-Fi, door codes, parking, and other everyday details where everyone can find them."
---

The **House guide** saves everyone from asking for the Wi-Fi password twice. Everyone in the stay can read it, and only the host can change it.

## What it can hold

- Wi-Fi network and password
- Mailing address and unit
- Door or gate code
- Parking instructions
- Trash and recycling schedule
- Emergency or building contact
- Important house notes

Leave anything blank that you don't need. Guests can copy details like the password or address with one tap.

## Edit it

Hosts open **House guide** on the web, make changes, and save. On iPhone, go to **More**, then **Host controls**.

<Tip>
  Door codes and passwords are visible to everyone in the stay, so update them after someone moves out.
</Tip>
