# Kouchd Help Center

This is the Mintlify help center for Kouchd. Content is organized into `hosts/`, `guests/`, and `legal-trust/` guides and configured in `docs.json`.

## Local preview

Install the Mintlify CLI and run `mint dev` from this directory to preview documentation changes. Check article links and images before publishing.

## Writing style

- Use direct, friendly language and address the reader as “you.”
- Keep Kouchd’s role clear: it records household agreements and contributions but does not process payments.
- Distinguish shared household information from each guest’s private agreement and ledger.
- Do not claim that Kouchd sends text messages or accesses contacts. Text invites are copied by the host and sent from the host’s phone.
